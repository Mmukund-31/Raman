# Data sources and provenance

| Item | Category | Origin | License |
|---|---|---|---|
| `data/references/*.csv` (polypropylene, ethanol, paracetamol, isopropanol, beta-carotene) | **synthetic** | `data/generate_synthetic.py`: Lorentzian bands at approximate literature band positions. Not measured. | Generated by this project; no third-party data |
| `data/examples/demo_*_synthetic.csv` | **synthetic** | Same generator, plus an invented baseline and Gaussian noise (fixed seed) | Same |
| Uploaded files | `user_supplied` | Provided by the user; RamanReach does not verify origin or calibration | n/a |

`manifest.json` in each folder records category, source, license and (for references) limitations. The `excitation_nm: 532` in the example manifest is a nominal value for the synthetic files.

## CubeRaman
[CubeRaman](https://github.com/jacobbusshart/CubeRaman) inspired this project. When checked on 2026-10-22 the repository page showed no LICENSE file, and its reference library is not published (only images of spectra). Therefore no CubeRaman code or data is reused. This check was from the GitHub page only; re-verify before any reuse.

No measured data has been added. Any future measured or third-party spectra must be added with documented instrument, excitation wavelength, units, source and license, and labelled `measured` or `reference` in the manifests.

## Added with the research labs
No new datasets, third-party code or downloaded data were added. Lab inputs are generated on demand from the synthetic references (`dataset_builder.py`, category **simulated**, seeds recorded). Dependencies added: scikit-learn (BSD-3-Clause, optional backend), PyTorch (BSD-style, optional, not bundled). Real paired/multi-instrument datasets (e.g. those used in arXiv:2601.16107) were **not** downloaded; their licences have not been reviewed.
