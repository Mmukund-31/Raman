# Limitations
- Reference library is synthetic (Lorentzian bands at approximate literature positions); real spectra differ in relative intensity, band width and instrument response.
- Thresholds (SNR 5, coverage 70%, score 0.6, margin 0.05) are heuristics, not validated cut-offs.
- No instrument calibration check; excitation wavelength is user-declared.
- No diagnostic, clinical or medicine-authenticity claims. Hardware (CubeRaman, Class 3B laser) requires trained operators.
- No deep learning: the library is far too small to support a trained model.
